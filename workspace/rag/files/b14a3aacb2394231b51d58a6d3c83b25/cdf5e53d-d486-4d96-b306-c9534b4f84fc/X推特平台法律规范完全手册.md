## 三、X 规则（The X Rules）

X 规则是平台内容治理的总纲，分为**安全（Safety）、隐私（Privacy）、真实性（Authenticity）**三大板块。官方页面：https://help.x.com/en/rules-and-policies/x-rules

### 3.1 安全（Safety）

| 规则 | 核心要求 |
|------|---------|
| **暴力内容** | 不得威胁、煽动、美化暴力或表达施暴意愿；适当标注且不过度血腥、不含性暴力的图形媒体可以分享 |
| **暴力与仇恨实体** | 不得附属于或宣传暴力、仇恨组织的活动 |
| **儿童安全** | 对儿童性剥削**零容忍**；并移除某些描绘儿童身体受虐的媒体以防止对儿童暴力的正常化 |
| **辱骂/骚扰** | 不得发布辱骂内容、针对个人的定向骚扰，或煽动他人这样做 |
| **仇恨行为** | 不得基于种族、族裔、国籍、种姓、性取向、性别、性别认同、宗教信仰、年龄、残障或严重疾病攻击他人 |
| **暴力袭击实施者** | 移除恐怖主义、暴力极端主义或大规模暴力袭击实施者运营的账号，及相关宣言传播内容 |
| **自杀与自残** | 不得推广或鼓励自杀、自残 |
| **成人内容** | 双方同意制作与分发的成人裸体或性行为内容，须**适当标注且不显著展示**方可分享 |
| **非法或特定管制商品/服务** | 禁止任何非法目的使用，包括买卖或促成非法及特定管制商品/服务交易 |

### 3.2 隐私（Privacy）

| 规则 | 核心要求 |
|------|---------|
| **私密信息** | 未经明确授权不得发布他人私密信息（住址、电话等）；禁止威胁曝光或利诱他人曝光 |
| **非自愿裸露（NCII）** | 不得发布/分享未经当事人同意制作的私密照片或视频 |
| **账号入侵** | 不得使用凭据、密码、令牌、密钥、Cookie 等登录或篡改他人账号（经 Teams 授权、OAuth 授权等除外） |

### 3.3 真实性（Authenticity）

| 规则 | 核心要求 |
|------|---------|
| **平台操纵与垃圾信息** | 禁止以人为放大或压制信息为目的使用服务，禁止操纵或破坏用户体验 |
| **公民诚信（选举诚信）** | 禁止操纵或干预选举等公民程序，包括压制参与或误导投票时间/地点/方式的内容 |
| **误导与欺骗性身份** | 禁止冒充个人、团体或组织误导他人；禁止以虚假身份干扰他人体验 |
| **合成与篡改媒体** | 禁止欺骗性分享可能造成危害的合成/篡改媒体；此类内容可能被加注标签 |
| **版权与商标** | 禁止侵犯他人知识产权（详见第六节） |

### 3.4 视频内容中的第三方广告

未经 X 事先同意，不得在视频内容中提交、发布或展示第三方广告（如前置视频广告或赞助商图形）。

## 四、主要内容政策详解

每条 X 规则均有配套的详细政策页（含违规认定标准与处罚阶梯）。重点政策：

### 4.1 暴力言论政策（Violent Speech）

- 禁止：暴力威胁、煽动暴力、美化暴力、表达希望他人受到暴力伤害
- 允许（有条件）：经正确标注、非显著展示、非过度血腥、不含性暴力的图形媒体；涉及公共利益的新闻报道内容（如战争报道）可获语境豁免

### 4.2 仇恨行为政策（Hateful Conduct）

- 受保护属性：种族、族裔、国籍、种姓、性取向、性别、性别认同、宗教信仰、年龄、残障、严重疾病
- 禁止：针对受保护属性的宣传暴力、威胁、骚扰、去人性化言论/图像，以及基于仇恨的 slur（脏字称呼）和恶意 stereotype
- 禁止在个人资料（用户名、显示名、简介）中使用仇恨符号与言论

### 4.3 平台操纵与垃圾信息政策（Platform Manipulation & Spam）

- 禁止使用多账号（账号矩阵）人为放大内容
- 禁止买粉、买互动、参与互推群（engagement pods）
- 禁止批量关注/取关、关键词自动回复、向新关注者发送未经请求的欢迎私信
- 禁止跨多账号发布相同或实质相似内容
- 禁止操纵话题标签（hashtag）与趋势（Trending）

### 4.4 合成与篡改媒体政策（Synthetic & Manipulated Media）

- 可能造成危害的欺骗性合成/篡改媒体将被移除或加注标签
- 判断维度：是否具欺骗性、是否可能造成危害（涉及公民诚信、暴力等）
- 深度伪造（deepfake）他人形象误导观众属于明显违规

### 4.5 公民诚信政策（Civic Integrity / Election Integrity）

- 禁止误导投票流程（时间、地点、资格、方式）
- 禁止压制投票率、恐吓或劝阻投票
- 禁止冒充选举机构或官员
- 涉选举的误导性内容可能被加注标签、降权或移除

### 4.6 媒体政策（Media Policy）与敏感内容

- 血腥暴力、成人内容须打上"敏感内容"标记，且不得用作头像或头图
- 直播中不得分享暴力或成人内容
- 描绘性暴力/性侵犯的媒体一律禁止

### 4.7 举报功能滥用政策（Report Abuse Policy）

- 禁止滥用举报机制打击报复或骚扰他人
- 恶意批量举报本身构成违规

## 五、隐私政策（Privacy Policy）

### 5.1 收集的信息

**用户提供的信息**：

- 账号信息：显示名、用户名、密码、邮箱/电话、出生日期、语言、第三方单点登录信息

- 支付信息：卡号、有效期、CVV、账单地址
- 生物识别信息（基于同意，用于安全与身份识别）
- 求职相关信息：履历、工作经历、教育背景、技能（用于职位推荐与向潜在雇主分享）

**使用过程中收集**：

- 帖文及发布元数据、Spaces 广播记录、列表、书签、社区
- 互动行为：转帖、点赞、回复、提及、关注关系
- **私信（DM）内容及收发时间**
- 设备信息：IP 地址、浏览器、操作系统、运营商、已安装应用、电量、通讯录（若授权）
- 位置信息（大致位置；精确位置可选共享）
- 日志信息：访问时间、浏览页面、搜索词（**含未提交的**）、广告展示记录
- Cookies 及类似技术；在第三方网站上与 X 内容的交互
- **未登录状态下也可能通过浏览器/设备指纹、邮箱哈希等推断身份**

**第三方来源**：广告合作伙伴、开发者、出版商提供的 Cookie ID、设备 ID、哈希邮箱、人口统计/兴趣数据，且可与已有信息合并。

### 5.2 使用目的

1. 运营、改进和个性化服务（推荐内容/广告/关注对象）——**含使用收集的信息和公开信息训练机器学习/AI 模型**
2. 促进安全与保障（身份验证、年龄估算/验证、反欺诈、政策执行）
3. 测量、分析与改进
4. 就服务与用户沟通
5. 研究（调研、产品测试、故障排查）

### 5.3 信息共享对象

- **公众**：X 是公开平台，资料信息公开可见，可能被搜索引擎收录
- **服务提供商**：支付、年龄验证、欺诈检测等（子处理者名单：https://privacy.x.com/subprocessors）
- **广告商与第三方合作者**：⚠️ 若用户不主动退出（opt out），数据接收方可将其用于自身目的，**包括训练其 AI 模型（无论是否为生成式）**；可通过隐私设置中 "Data sharing with business partners" 控制
- **API 第三方**：公开信息通过 API 提供给网站、应用等
- **法律要求/防止伤害/公共利益**：响应法律程序与政府请求、防欺诈、保护人身安全、KYC/KYB 合规
- **关联公司之间**；**所有权变更**（合并、收购、破产）时可能共享、出售或转让

### 5.4 数据保留期限

## 九、执法机制与申诉流程

### 9.1 执法手段阶梯

X 采用分级执法（enforcement）体系，从轻到重：

1. **内容降权/限制可见性**（limiting reach of violating posts）
2. **要求删除违规帖文后恢复使用**（tweet deletion）
3. **临时锁定**（12 小时至 7 天不等，需验证邮箱/手机）
4. **限制模式**（limited mode，功能受限）
5. **加注标签**（敏感内容、 manipulated media、国家媒体标签等）
6. **永久封禁**（permanent suspension）——保留给严重违规或持续、重复违规

**封禁常见触发原因**：垃圾行为（批量关注、重复发帖、自动化滥用）、账号安全风险、辱骂内容（骚扰、威胁、仇恨、曝光隐私）。

**严重违规类型**（可首次即永久封禁）：非法内容或活动、煽动或威胁暴力、隐私侵犯、平台操纵或垃圾信息、定向骚扰。

### 9.2 规避执法的后果

- 被封禁后**创建新账号规避封禁本身构成违规**；通过相同手机号、邮箱或设备指纹关联的新账号通常会被再次封禁

### 9.3 申诉流程（Appeals）

- 官方申诉表单：https://help.x.com/forms/account-access/appeals
- 须登录被封账号，提供用户名、邮箱、电话及事实性说明
- 审核周期：一般 48–72 小时，复杂案件 1–8 周
- 建议：提交一次完整、基于事实的申诉，**重复滥发申诉会触发自动拒绝**
- 被认定封禁有效时，X 会回复所违反的具体政策

### 9.4 用户救济渠道（欧盟/英国）

- **欧盟用户**：可依据《数字服务法》（DSA, Regulation (EU) 2022/2065）通过 X 内部投诉程序或庭外争议解决机制（ODR）质疑平台的执法决定

## 十一、对内容创作者的合规要点

结合平台规则，创作者发帖时应重点自查：

1. **暴力与仇恨红线**：不威胁、煽动、美化暴力；不针对受保护属性（种族、性别、宗教等）发布攻击性内容
2. **成人/血腥内容须标注**：默认打"敏感内容"标签，且不得用作头像/头图
3. **不曝光他人隐私**：住址、电话、身份证件等私密信息未经授权不得发布（即使出于"爆料"目的）
4. **真实身份**：不冒充他人或机构；仿冒账号、误导性改名会被处理
5. **合成媒体要披露**：AI 生成的深度伪造若具欺骗性且可能致害会被移除；主动标注可降低风险
6. **避免平台操纵行为**：不买粉、不参与互赞群、不跨号发重复内容、不滥用话题标签；这些是自动封号的高频触发点
7. **尊重版权**：转发媒体须有权利基础；重复侵权会导致永久封禁
8. **私信同样受规则约束**：未经请求的批量私信构成垃圾信息
9. **注意授权范围**：发布即授予 X 全球免版税可再许可的广泛许可（含 AI 训练用途，非欧盟用户无退出机制）——对高价值原创内容（摄影、插画、长文）需有心理预期
10. **付费合作须标注**：商业推广使用平台的合作标注功能；视频中不得嵌入未经批准的第三方广告
11. **被处罚后**：先查具体违规政策，通过官方表单一次性提交有据申诉；不要立即注册新号规避
